# 全界面视觉统一（2.2-beta）

视觉修改已完成本地体验检查；用户随后授权发布网站并打包安卓独立应用版。本版为 `2.2-beta`，安卓版本号 13。

## 范围和保留项

- 五个功能页、登录／注册与安装引导、推荐结果及核对／发布设置、加载画面、个人主页与其他弹窗、后台共用样式和开屏标题。
- 主标题采用 600 字重、0.045em 字距、稍亮深紫，功能页保持单行；常规主标题字号约缩小 8%—9%。
- 长欢迎语和动态活动名称保留自然断行，不为了单行缩成小字。
- 共用暖白表面与轻阴影；浅黄／夜间琥珀只用于标签、星星和底部选中项。底部所有选中项保持黄底、紫色文字，未选中项为灰紫。
- 保留页面结构、卡片顺序、花朵 SVG、信用模块、主要紫色按钮和中文文案。没有改业务逻辑。
- 修复手机标题／正文与插画靠得过近、320px 画像标题越出容器、长昵称撑开界面、流程提示在浅色中过淡、深色加载步骤图标仍为白底的问题。
- 同步入口样式版本及离线缓存列表；开屏资源也加上版本参数，避免继续复用旧标题样式。
